# Content Management User Guide

## D7 TechNode Website CMS

Welcome to the D7 TechNode Content Management System! This guide will help you manage website content without any programming knowledge.

## 🌟 Getting Started

### Accessing the CMS

1. Open your web browser
2. Go to: `https://your-website.com/studio` or your Sanity Studio URL
3. Sign in with your credentials

## 📚 Managing Resources & Manuals

### Adding a New Resource

1. **Navigate to Resources**
   - Click on "Resources & Manuals" in the left sidebar
   - Click the green "+" or "Create" button

2. **Fill in the Details**
   - **Title**: Enter the name of your resource (e.g., "Product User Manual v2.0")
   - **Slug**: This creates the URL - it auto-generates from the title
   - **Category**: Choose from:
     - User Manual
     - Technical Documentation
     - Product Guide
     - Training Material
     - White Paper
     - Case Study
     - Other

3. **Add Description**
   - Write a brief summary (2-3 sentences)
   - This appears in search results

4. **Upload Your File**
   - Click "Upload" under "Upload File"
   - Select your file (PDF, Word, Excel, PowerPoint, ZIP)
   - Wait for upload to complete
   - OR paste an external URL if hosted elsewhere

5. **Add a Cover Image** (Optional)
   - Click "Upload" under "Cover Image"
   - Choose an image that represents then resource
   - Recommended size: 1200 x 800 pixels

6. **Add Tags**
   - Type keywords and press Enter
   - Examples: "beginner", "installation", "troubleshooting"
   - Tags help users find your resource

7. **Mark as Featured** (Optional)
   - Toggle "Featured Resource" ON for important items
   - Featured items appear at the top

8. **Publish**
   - Click "Publish" button
   - Your resource is now live on the website!

### Editing an Existing Resource

1. Click on "Resources & Manuals" in the sidebar
2. Find and click on the resource you want to edit
3. Make your changes
4. Click "Publish" to save

### Deleting a Resource

1. Open the resource you want to delete
2. Click the three dots menu (⋯) at the top
3. Select "Delete"
4. Confirm deletion

## 🛠️ Managing Services

### Adding a Service

1. Click "Services" in the sidebar
2. Click "Create"
3. Fill in:
   - **Title**: Service name (e.g., "Cloud Solutions")
   - **Slug**: Auto-generates from title
   - **Short Description**: One paragraph overview
   - **Full Description**: Detailed information
   - **Icon Name**: Choose from: Cloud, Brain, Lock, Code, Database, Smartphone
   - **Service Image**: Upload a relevant image
   - **Key Features**: Click "+ Add item" for each feature
   - **Display Order**: Number to control order (1 = first)
4. Click "Publish"

## 📦 Managing Products

### Adding a Product

1. Click "Products" in the sidebar
2. Click "Create"
3. Fill in:
   - **Product Name**: Full product name
   - **Description**: Brief overview
   - **Full Description**: Detailed information
   - **Product Image**: Main product image
   - **Image Gallery**: Additional images (click "+ Add item")
   - **Features**: List key features
   - **Pricing**:
     - Price: Number only (e.g., 99.99)
     - Currency: USD, EUR, etc.
     - Billing Period: one-time, monthly, yearly, or custom
   - **Category**: Software, Hardware, Service, or Platform
   - **Featured Product**: Toggle ON for homepage display
4. Click "Publish"

## 📄 Managing Pages

### Editing Page Content

1. Click "Pages" in the sidebar
2. Select the page you want to edit
3. Use the rich text editor:
   - **Bold**: Ctrl+B / Cmd+B
   - **Italic**: Ctrl+I / Cmd+I
   - **Headings**: Click the heading dropdown
   - **Links**: Highlight text, click link icon
   - **Images**: Click the image icon to upload
4. Click "Publish" to save

## 💡 Best Practices

### Images

- ✅ Use high-quality images
- ✅ Recommended size: 1200 x 800 pixels
- ✅ File formats: JPG, PNG, WebP
- ✅ Keep file sizes under 2MB
- ✅ Use descriptive alternative text

### Writing Content

- ✅ Keep titles clear and descriptive
- ✅ Write in simple language
- ✅ Use bullet points for easy scanning
- ✅ Proofread before publishing
- ✅ Update dates when revising content

### Organization

- ✅ Use consistent naming conventions
- ✅ Add relevant tags to all resources
- ✅ Keep categories organized
- ✅ Archive outdated content
- ✅ Regular content audits

### File Uploads

- ✅ Name files clearly (e.g., "User-Manual-v2.0.pdf")
- ✅ Ensure files are virus-free
- ✅ Compress large files
- ✅ Test downloads after uploading
- ✅ Version control important documents

## 🔍 Search & Filter Tips

### Making Content Discoverable

1. **Use Descriptive Titles**
   - Good: "Installation Guide for CloudSync Pro"
   - Bad: "Guide 1"

2. **Add Multiple Tags**
   - Include variations
   - Example: "install", "installation", "setup", "getting started"

3. **Write Clear Descriptions**
   - Include key terms users might search for
   - Mention version numbers if applicable

4. **Choose Correct Categories**
   - Helps users filter results
   - Be consistent across similar resources

## ⚠️ Common Issues & Solutions

### "Unable to Upload File"

- Check file size (max 100MB)
- Ensure file type is supported
- Try a different browser
- Clear browser cache

### "Changes Not Appearing on Website"

- Make sure you clicked "Publish"
- Wait 1-2 minutes for cache to clear
- Refresh the browser (Ctrl+F5 / Cmd+Shift+R)

### "Can't Find Uploaded Resource"

- Check if it's published (not draft)
- Verify category selection
- Check search spelling

### "Lost Changes"

- CMS auto-saves every few minutes
- Look for draft versions
- Contact support if needed
