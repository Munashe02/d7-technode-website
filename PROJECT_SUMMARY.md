## 🎯 For Non-Programmers

### How to Add Resources/Manuals

1. **Go to**: `http://localhost:3000/studio` (or your deployed URL + `/studio`)
2. **Click**: "Resources & Manuals"
3. **Click**: "Create" button
4. **Fill in**:
   - Title (e.g., "User Manual v2.0")
   - Category (choose from dropdown)
   - Description (brief summary)
   - Upload your file (PDF, Word, etc.)
   - Add tags (optional, for search)
5. **Click**: "Publish"

**That's it!** Your resource is now live on the website.

## 🚀 Next Steps

### Immediate (Before Launch)

1. **Set Up Sanity CMS** (5 minutes)
   - Create free account at sanity.io
   - Get your Project ID
   - Update configuration files

2. **Install Dependencies** (3 minutes)

   ```powershell
   npm install
   cd sanity && npm install && cd ..
   ```

3. **Configure Environment** (2 minutes)
   - Copy `.env.example` to `.env.local`
   - Add your Sanity Project ID

4. **Start Development** (1 minute)

   ```powershell
   npm run dev
   ```

5. **Add Initial Content** (10 minutes)
   - Go to `http://localhost:3000/studio`
   - Add a few resources
   - Add services
